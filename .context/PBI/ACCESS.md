## 4. Project Structure

**Issue types in use** (per `.agents/jira-required.yaml`, ported from upstream 2026-09-01, 14 work types cataloged): Epic, Story, Bug, Defect, Improvement, Tech Story, Tech Debt, Test (`test_case`), Test Plan, Test Execution, Precondition, Test Set, and the subtask level named `Task` on `BK`.

**Workflow states**: resolved live via `.agents/jira-fields.json` / `jira-workflows.json` slugs (`{{jira.status.<work_type>.<slug>}}`), not frozen literals in this document — status IDs have already moved twice across the `upexgalaxy71` → `upexgalaxy72` restores (see AGENTS.md §13.1). Re-run `bun run jira:sync-workflows --force` after any future instance migration before trusting a cached status name.

**Sprint cadence**: Scrum, sprints resolved via JQL `sprint in openSprints()` / `--sprint <active|current|closed|>=N|7,8,10>` per `bun run jira:sync-issues`. Naming convention not verified in this pass — see Discovery Gaps.

**QA-process parenting (three-axis model)**: every quality issue (`bug`/`defect`/`improvement`) parents to the **"QA Defect Management"** epic, every `Test` to **"QA Test Repository"**, every Test Plan to **"QA Master Test Plan"**, every Test Execution/Precondition/Test Set to **"QA Test Artifacts"** — never a product/dev epic. Traceability to the source Story is an issue-link, not the parent. Full doctrine: `agentic-qa-core/references/defect-management-doctrine.md`.

## 5. Common Queries

| Need | JQL |
|---|---|
| Current sprint ready for QA | `project = BK AND sprint in openSprints() AND status = "{{jira.status.story.ready_for_qa}}"` |
| All open bugs | `project = BK AND type = Bug AND resolution = Unresolved ORDER BY priority DESC` |
| My testing tasks | `project = BK AND status = "{{jira.status.story.in_test}}" AND assignee = currentUser()` |
| Recently updated | `project = BK AND updated >= -1d ORDER BY updated DESC` |

`[ISSUE_TRACKER_TOOL]` pseudocode equivalents:

```
[ISSUE_TRACKER_TOOL] Search Issues:
  project: BK
  query: sprint in openSprints() AND status = "{{jira.status.story.ready_for_qa}}"

[ISSUE_TRACKER_TOOL] Get Issue:

```
